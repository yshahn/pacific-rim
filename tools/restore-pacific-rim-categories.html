🍣 Pacific Rim Bistro — Category Restorer

One-time tool to restore the original category tabs and section config, which were accidentally overwritten while building Hsu's Gourmet.

✅ This restores config/categories and config/sections, and re-tags the subcat field on existing menu items so the admin accordion groups work again.
Item names, prices, descriptions, images, and options are never modified — only the internal subcat grouping tag is added back where it belonged.
⚠️ This writes to the pacific-rim-bistro Firebase project (not Hsu's). Only run this once.
